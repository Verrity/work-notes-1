Инструкция для nodejs в контуре:
1. Установка portable Node.js
Команда ниже ставит portable Node.js в домашний каталог пользователя, не заменяя системный node.
```
mkdir -p "$HOME/.local/lib/nodejs" && \
wget -O "/tmp/node-v24.16.0-linux-x64.tar.xz" "http://s3.mes-services.eltex.loc/third-party/node-v24.16.0-linux-x64.tar.xz" && \
rm -rf "$HOME/.local/lib/nodejs/node-v24.16.0" && \
tar -xJf "/tmp/node-v24.16.0-linux-x64.tar.xz" -C "$HOME/.local/lib/nodejs" && \
mv "$HOME/.local/lib/nodejs/node-v24.16.0-linux-x64" "$HOME/.local/lib/nodejs/node-v24.16.0" && \
rm -f "/tmp/node-v24.16.0-linux-x64.tar.xz" && \
grep -qxF 'export PATH="$HOME/.local/lib/nodejs/node-v24.16.0/bin:$PATH"' "$HOME/.bashrc" || \
echo 'export PATH="$HOME/.local/lib/nodejs/node-v24.16.0/bin:$PATH"' >> "$HOME/.bashrc" && \
export PATH="$HOME/.local/lib/nodejs/node-v24.16.0/bin:$PATH"
```

2. Настройка npm на внутренний Nexus
```
cat > ~/.npmrc <<'EOF'
@angular:registry=http://nexus.eltex.loc:8081/repository/npm-proxy/
@nodelib:registry=http://nexus.eltex.loc:8081/repository/npm-proxy/
@mrmlnc:registry=http://nexus.eltex.loc:8081/repository/npm-proxy/
registry=http://nexus.eltex.loc:8081/repository/npm-proxy/
strict-ssl=false
EOF
```

3. Настройка пользовательского prefix для global npm-пакетов
Это нужно, чтобы не использовать sudo npm install -g.
```
mkdir -p "$HOME/.local/npm-global"
npm config set prefix "$HOME/.local/npm-global"
echo 'export PATH="$HOME/.local/npm-global/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```
